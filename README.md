# Sillon Bulletins — application Mac

Remplit automatiquement les bulletins de souscription SCPI à partir de la
fiche du client (ou de son recueil d'informations en PDF). Les bulletins
restent modifiables après remplissage : relisez-les avant de les faire signer.

**Télécharger :** [Sillon-Bulletins-Mac.zip](https://github.com/favereaukevin-creator/sillon-bulletins-telechargements/releases/latest/download/Sillon-Bulletins-Mac.zip)

Compatible Mac Intel et Apple Silicon, macOS 11 ou plus récent.

## Installation

1. Double-cliquer sur le fichier `.zip` téléchargé : l'application
   **Sillon Bulletins** apparaît.
2. La glisser dans le dossier **Applications**.

## Au premier lancement : macOS va bloquer l'application

C'est normal : l'application n'est pas signée par un compte développeur
Apple payant. macOS affiche un message du type « Apple ne peut pas
vérifier que Sillon Bulletins ne contient pas de logiciel malveillant ».

Une seule fois :

1. Ouvrir le dossier **Applications**.
2. **Clic droit** sur Sillon Bulletins → **Ouvrir**, puis **Ouvrir** à nouveau.

Si macOS ne propose que « Placer dans la corbeille » (macOS 15 et plus) :
**Réglages Système → Confidentialité et sécurité**, faire défiler jusqu'au
message concernant Sillon Bulletins et cliquer **Ouvrir quand même**.

## Les données

Tout reste sur l'ordinateur : les fiches clients, le recueil lu et les
bulletins remplis ne sont envoyés nulle part.
